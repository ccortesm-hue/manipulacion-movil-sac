# R2: referencias de velocidad

Entorno con residual sobre referencias cinemáticas. Es una línea adicional; la comparación principal de la tesis usa baseline, R1.1 y R3.

## Preparación

Desde la raíz del repositorio, ejecutar `python herramientas/preparar_entorno.py`. `MM_DATA_VXR2.py` → `VX/`; el preparador crea también el nombre `zenno_vx_r2.py` que espera el contrato.

Las dependencias y las instrucciones comunes están en [docs/EJECUCION.md](../../docs/EJECUCION.md). Los pesos y normalizadores no se publican. Los lanzadores originales, cuando existen, se conservan en `lanzadores_originales/`; pueden contener rutas del equipo Ubuntu de origen.
