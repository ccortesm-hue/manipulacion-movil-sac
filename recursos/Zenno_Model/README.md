# Modelo físico del manipulador móvil

`scene.xml` es la escena principal; incluye `bunker4.xml`, las mallas de `assets/` y la textura de `texture/`. `scene_base.xml` conserva una escena alternativa y `bunker3.xml`, otra descripción de la base.

Se distribuyen los archivos geométricos y físicos originales. Este directorio no contiene pesos ni políticas aprendidas. Se puede abrir `scene.xml` con `python -m mujoco.viewer --mjcf=recursos/Zenno_Model/scene.xml` desde la raíz del repositorio.
