# Mapas y rutas de navegación

`map_1.json` a `map_4.json` contienen las rutas de los cuatro escenarios. `manifest.json` registra parámetros de planificación y validación. Las imágenes PNG permiten consultar las rutas sin ejecutar los controladores.

Se conservan los bytes originales para mantener las verificaciones de integridad de los experimentos. El preparador copia los recursos a `.runtime/RUTAS_SAC/`.
